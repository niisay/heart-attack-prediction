# Heart Attack Prediction Project ❤️

## 📌 Project Description
This project aims to predict the likelihood of a heart attack using machine learning algorithms based on medical data.

## 🧠 Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  

## 📊 Features
- Data preprocessing  
- Missing value analysis  
- Feature selection  
- Model training and evaluation  

## 🎯 Goal
To analyze medical data and build a model that can estimate the risk of heart attack.

## 📁 Dataset
The dataset used in this project is obtained from Kaggle.

## 🚀 Status
Completed as part of a data mining / machine learning study.
